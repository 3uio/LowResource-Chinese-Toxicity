# 环境搭建说明（Track A 交付物）

**用途**：让任何一位成员从零把环境装到「能跑通 `train.py`」。
**验证环境**：Windows + Python **3.13.14**（Linux/macOS 同样适用，命令差异已标注）。
**配套文件**：[`requirements.txt`](requirements.txt)（依赖清单）、[`README.md`](README.md)（框架使用说明）。

> 本说明里的每一步都在本机实测通过，包含几个**必须知道、否则会卡很久**的坑（见第 8 节）。

---

## 0. 一句话总览

```
Python 3.13  →  建虚拟环境  →  先装 PyTorch  →  装其余依赖  →  下载模型  →  跑通验证
   (§1)           (§2)           (§3)            (§4)          (§6)         (§7)
```

**核心依赖只有 5 个**：`torch`、`transformers`、`adapters`（= `adapter-transformers`）、`accelerate`、`scikit-learn`。
其余全是它们的间接依赖，`requirements.txt` 里已经固定好版本。

## 2. 第 1 步：建虚拟环境

**为什么必须建**：把本项目的包装在独立目录里，不污染系统 Python、也不影响其他项目。

```bash
# ① 在项目根目录下创建（项目内的 .venv/ 已在 .gitignore 里，不会被提交）
python -m venv .venv

# ② 激活
#    Windows (PowerShell)
.venv\Scripts\Activate.ps1
#    Windows (cmd)
.venv\Scripts\activate.bat
#    Linux / macOS
source .venv/bin/activate

# ③ 确认激活成功（路径里应出现 .venv）
python -c "import sys; print(sys.executable)"
```

> ⚠️ **虚拟环境不能跨机器复制**。它内部记录的是**绝对路径**，换台电脑就失效。
> 所以在服务器上必须**重新建一次**（用同样的 `requirements.txt`）。

---

## 3. 第 2 步：装 PyTorch（⚠️ 必须排在其余依赖之前）

### 为什么要先装

`adapters` / `transformers` 会把 `torch` 当作依赖。如果你直接 `pip install -r requirements.txt`，
pip 会自动从默认源拉一个 torch —— **那个版本不一定匹配你的显卡驱动**。
**先把 torch 装好，pip 后面就会发现"已满足"而不再动它。**

### 按机器类型二选一

```bash
# 【GPU 机器】CUDA 版本要和你显卡驱动匹配（这里是 cu124 示例）
pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu124

# 【CPU 机器】本地写代码 / 调试验证用，体积小很多（约 115 MB）
pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
```

### 国内网络直连不通时的绕法（实测）

PyTorch 官方源在国内**经常连不上**。走阿里云的镜像：

```bash
# ⚠️ 这个地址是「文件列表页」，不是 pip 索引格式，必须用 -f（--find-links），
#    不能用 -i（--index-url）—— 用错会报「找不到满足要求的版本」
pip install torch==2.11.0+cpu --no-deps --no-index -f https://mirrors.aliyun.com/pytorch-wheels/cpu/

# 装完后补上它的纯 Python 依赖
pip install sympy networkx jinja2 -i https://mirrors.aliyun.com/pypi/simple/
```

> **上云服务器时更省事的做法**：AutoDL 这类平台都有**预装好 PyTorch 的镜像**，
> 选中之后 CUDA 和 torch 版本都是配好的 —— 这是最不容易翻车的一步。

### 验证

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
# CPU 版输出 True/False 都正常（False 表示没装 CUDA 版）
```

## 4. 第 3 步：装其余依赖

```bash
# ⚠️ 必须用阿里源：adapters / adapter-transformers 这两个包【清华源没有】
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

**关于 `adapter-transformers` 这个包名**：

| 包名 | 说明 |
|---|---|
| `adapter-transformers` | **安装入口**，装它会自动带上下面的 `adapters` |
| `adapters` | **真正的库**（代码里 `import adapters` 指的是它）。1.3.0 |

两个都写在 `requirements.txt` 里，装一次即可。

**装完必须有的几个包**（缺任何一个都会在训练时报错）：

```bash
python -c "import torch, transformers, adapters, accelerate, sklearn; print('OK')"
```

| 包 | 缺了会怎样 |
|---|---|
| `accelerate` | ⚠️ `Trainer` **强制依赖**，缺了直接报 `ImportError` |
| `scikit-learn` | ⚠️ 算 `macro_f1` 要用，评估阶段报错 |

> 这两项**不在**上一版的 `requirements_当前环境.txt` 里（那份是早期快照，已删除），
> 现在的 `requirements.txt` 已补全。

## 6. 第 5 步：下载模型

**模型不在仓库里**（体积大 + 跨机器无效），要自己下。两个脚本依次跑：

```bash
# ① 主干模型 xlm-roberta-base（约 1.1 GB）+ 中文语言适配器
python 框架开发/02_下载与推理验证.py

# ② 英语语言适配器（MAD-X + TLR 需要，约 30 MB）
python 框架开发/04_下载语言适配器.py
```

下完之后，模型会放在项目根目录的 **`.model_cache/`** 下（已在 `.gitignore` 里）：

```
.model_cache/
├── xlm-roberta-base/                      ← 主干（约 1.12 GB）
├── xlm-roberta-base-zh-wiki_pfeiffer/     ← 中文语言适配器
└── xlm-roberta-base-en-wiki_pfeiffer/     ← 英语语言适配器
```

### ⚠️ 下载相关的两个环境变量（脚本里已设好，这里说明原因）

| 变量 | 值 | 为什么必须 |
|---|---|---|
| `HF_ENDPOINT` | `https://hf-mirror.com` | `huggingface.co` 国内直连不通 |
| `HF_HUB_DISABLE_XET` | `1` | ⚠️ 不禁用的话，hf-mirror 会把大文件重定向到 `cas-bridge.xethub.hf.co`，**该域名在国内会超时** |

脚本里已经用 `os.environ.setdefault(...)` 设好了，**正常情况不用手动加**。
如果你要用别的方式下载，记得自己设上这两个。

### 关于语言适配器（不用自己训）

两个语言适配器都是 **AdapterHub 上现成的**，一行代码加载，许可 Apache-2.0：

| 语言 | 地址 |
|---|---|
| 中文 | `AdapterHub/xlm-roberta-base-zh-wiki_pfeiffer` |
| 英语 | `AdapterHub/xlm-roberta-base-en-wiki_pfeiffer` |

（中文那个在中文维基上做过 25 万步 MLM，正是 XLM-R-base 的版本。）

## 8. 已知的坑（都实测踩过，照做可绕过）

| # | 现象 | 原因 | 解法 |
|---|---|---|---|
| 1 | `pip` 报「找不到满足要求的版本 adapters」 | **清华源没有这个包** | 换**阿里源** `-i https://mirrors.aliyun.com/pypi/simple/` |
| 2 | 装 CPU 版 torch 报「找不到满足要求的版本」 | 阿里那个地址是**文件列表页**，不是 pip 索引 | 用 `-f`（find-links）而不是 `-i`，见 §3 |
| 3 | 下载 adapter 报 `cas-bridge.xethub.hf.co ... Read timed out` | HuggingFace 的新存储后端被墙 | 设 `HF_HUB_DISABLE_XET=1` |
| 4 | 模型加载报 `JSONDecodeError`，而某些 `.json` 是 **0 字节** | huggingface_hub 默认建**符号链接**，Windows 下创建失败留下空文件 | 用 `local_dir` 下载（脚本已用）；脚本内已加**自愈检查**会自动补下 0 字节文件 |
| 5 | `Trainer` 报 `Using the Trainer with PyTorch requires accelerate` | `transformers` / `adapters` **不会自动带** `accelerate` | `pip install accelerate`（已进 requirements） |
| 6 | 训练报 `did not return a loss ... only logits` | `Trainer` 默认按模型签名过滤输入列，`AutoAdapterModel` 是**动态签名**、不含 `labels`，标签被静默删除 | `TrainingArguments(remove_unused_columns=False)`（框架里已设） |
| 7 | 指标全空 / `predictions.csv` 只有 1 行 | 同上根因：`Trainer` 推断不出标签列 | 显式补 `label_names=["labels"]`（框架里已设） |

**第 4、6、7 条是最隐蔽的** —— 它们不报明显错误，只是结果不对。框架代码里已经处理好了。

## 9. `adapters` 的 API 与网上教程不一样（重要）

网上的 adapter 教程大多基于旧版本，照抄会连环报错。当前版本（`adapters` 1.3.0）实测用法：

| 操作 | 正确写法 |
|---|---|
| 构造配置 | `AdapterConfig.load("pfeiffer", reduction_factor=16)` —— ❌ 不是 `PfeifferConfig` |
| 取句子表示 | `model.base_model(**enc)` —— ❌ 直接 `model(**enc)` 返回的是 MLM 输出，**没有** `last_hidden_state` |
| 设激活的分类头 | `model.active_head = "toxic"` —— ❌ **没有** `set_active_head()` 这个方法 |
| 训练某个 adapter | `model.train_adapter("task")`（会自动冻结其他参数） |
| 叠加多层 | `model.set_active_adapters(Stack("lang", "task"))` |
| 排查看某方法签名 | 这些方法是**动态注入到实例**的，`inspect.signature(类.方法)` 会报错，**要在实例上取** |

## 10. 上云服务器时怎么迁移

| 项 | 做法 |
|---|---|
| **虚拟环境** | ❌ **不能复制**（内含绝对路径）→ 在服务器上按 §2–§4 重建 |
| **依赖版本** | ✅ 用 `requirements.txt`（唯一能对齐两边的文件） |
| **模型** | 在服务器上重跑 §6 两个脚本（或在平台缓存中复用） |
| **数据** | 从对应 Track 获取（不在仓库里，见 README） |
| **加速** | 优先选平台的**预置 PyTorch 镜像**（省掉 CUDA 匹配的麻烦） |
| **省时间** | 环境配好后可在平台上**存成自定义镜像**，下次开机直接选 |

**"本地能跑、服务器报错"最常见的原因是依赖版本不一致** —— 所以务必用同一份 `requirements.txt`。

## 附：出问题时先查这几处

1. 是不是**忘了激活**虚拟环境（`python -c "import sys; print(sys.executable)"` 看路径）
2. 是不是**没先装 torch**（会拉到不匹配的版本）
3. 是不是用了**清华源**（`adapters` 装不上）
4. 模型目录 `.model_cache/` 下有没有 **0 字节的 `.json`**（坑 4）
5. `accelerate` / `scikit-learn` 装了没（坑 5）
