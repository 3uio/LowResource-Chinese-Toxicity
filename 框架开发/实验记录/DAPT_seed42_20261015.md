# DAPT seed42 首次云端实验

训练日期：2026-10-15；本地验收与记录更新：2026-10-16。

## 目的与状态

在已有 XLM-R-base 上做中文领域 MLM 继续预训练，为 B 的 DAPT+FT 分类对照提供候选底座。此次只验收 MLM 训练与交付接口，尚未验证毒性分类 F1、误伤率或扰动鲁棒性增益。

在 pilot 下游分类对照尚未完成时，团队执行了耗时较短的全量单轮。不能将本次全量完成理解为 pilot 的下游效果门槛已经通过。

## 调试与验收

1. FP16 两步烟雾测试虽然正常退出、loss 有限，202 个共同参数张量却均未改变；Adam 状态 step 为 0，梯度缩放器连续降低。判为更新被跳过，不能作为成功训练。
2. BF16 十步烟雾测试中，202 个共同张量全部改变，Adam step 为 10，固定验证 loss 4.528963 降至 4.440321。
3. 全量启动时曾重复执行后台命令，先停止重复链的外层脚本以避免误触发关机，再停止重复训练，只保留原运行。最终验收的是 `bf16_full_20261015T145750Z_4002`，不是按启动器共享日志猜测实验身份。
4. 下载包 SHA256 与服务器记录一致。划分 ID 与顺序由上传时的代码快照复算一致，train/validation 归一化哈希交集为 0；冻结隔离审计通过。范围不扩展为所有未来 C/D 数据已审计。
5. 全量权重无 NaN/Inf，202 个共同参数张量相对原底座全部变化。原底座多出的两个 pooler 张量未用于 MLM 属预期结构差异。
6. 全量产物可离线加载并完成有限值 MLM 前向；使用分类框架以 `backbone` 加载，可新建分类头并得到有限值 logits。这不是下游分类训练结果。
7. 原始与交付分词器的运行时词表、处理组件一致，全部 27,851 条文本 token ID 一致。transformers 4.57.6 的宽泛 Mistral regex 警告在此未形成可观测分词差异，未盲目修改分词器。

## 限制与后续

- 当前只跑一个 DAPT seed 和一轮训练；是否采用该底座由 B 在固定分类数据/超参/多 seed 条件下对照评估，D 配合统计。
- 下载交付包不包含 optimizer 检查点，全量的 827 是 Trainer 计数，不能从此包独立复核 Adam 的实际累计步数；全量参数确实变化已单独核验。
- 发布版脚本在训练后增加 Adam 非零 step 检查与 `optimizer_step_values` 指标，已做小模型回归。历史云端运行早于该检查，没有该指标字段；没有为补字段重跑训练或改写原始结果。
- 聚合结果公开；真实语料、模型、行 ID 清单与原始交付包由团队私下传递，不进入 Git。
